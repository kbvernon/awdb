# Datasets

Arbitrary bounding boxes drawn around potential areas of interest.

## Usage

``` r
bear_lake

cascades
```

## Format

An object of class `sfc_POLYGON` (inherits from `sfc`) of length 1.

## Source

Coordinates digitized manually.

## Details

Areas of interest include:

- Bear Lake along the border between Utah and Idaho. See [location on
  Google Maps](https://maps.app.goo.gl/bDBFyFhNgYbfvwuw8).

- Cascades in west central Oregon. See [location on Google
  Maps](https://maps.app.goo.gl/sBtTHaN8SeM6xJWv7).
